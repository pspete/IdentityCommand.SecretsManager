# Get-SMModuleData

## SYNOPSIS
Get the module version and session configuration data

## SYNTAX

```
Get-SMModuleData [-InformationVariable <String>] [-WarningVariable <String>] [-OutVariable <String>] [-PipelineVariable <String>] [-OutBuffer <Int32>] [-ErrorVariable <String>] [-Debug] [-Verbose] [-ErrorAction <ActionPreference>] [-InformationAction <ActionPreference>] [-WarningAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION
Returns values of variables from the script scope of the IdentityCommand.SecretsManager module, including the last command, last command results, and session elapsed time.

## EXAMPLES

### Example 1
```
Get-SMModuleData
```

Get the module version and session configuration data
