# Set-SMAuthenticatorState

## SYNOPSIS
Enables or disables an authenticator

## SYNTAX

```
Set-SMAuthenticatorState [-enabled] <Boolean> [-name] <String> [-type] <String> [-InformationVariable <String>] [-WarningVariable <String>] [-OutVariable <String>] [-PipelineVariable <String>] [-OutBuffer <Int32>] [-ErrorVariable <String>] [-Debug] [-Verbose] [-ErrorAction <ActionPreference>] [-InformationAction <ActionPreference>] [-WarningAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Updates the enabled field of the specified authenticator - currently the only field this endpoint supports updating.

## EXAMPLES

### Example 1
```
Set-SMAuthenticatorState
```

Enables or disables an authenticator
