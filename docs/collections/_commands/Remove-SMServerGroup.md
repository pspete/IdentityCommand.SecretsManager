# Remove-SMServerGroup

## SYNOPSIS
Deletes a SWA server group

## SYNTAX

```
Remove-SMServerGroup [-serverGroupName] <String> [-trustDomainName] <String> [-InformationVariable <String>] [-WarningVariable <String>] [-OutVariable <String>] [-PipelineVariable <String>] [-OutBuffer <Int32>] [-ErrorVariable <String>] [-Debug] [-Verbose] [-ErrorAction <ActionPreference>] [-InformationAction <ActionPreference>] [-WarningAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Deletes the SWA server group, and every server in it and their related Secrets Manager resources.

## EXAMPLES

### Example 1
```
Remove-SMServerGroup
```

Deletes a SWA server group
